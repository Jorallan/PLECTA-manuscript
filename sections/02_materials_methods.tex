\section{Materials and methods}
\label{sec:methods}

\subsection{CNT material and SEM imaging}
\label{sec:mm-sem}
The real micrographs analysed here are grayscale secondary-electron SEM images of
carbon nanotube bundle mats. The reference acquisition has a horizontal field
width of $1.66~\um$; the instrument metadata reports this field width over
$1536$~px, giving a physical pixel size of
$u_{\text{ref}}=1.66/1536\approx1.081\times10^{-3}~\um\,\text{px}^{-1}$
($\approx1.08$~nm/px), and the stored micrographs measure $1534\times1026$~px
after removal of the instrument data bar. Images are 8-bit grayscale and are used
without intensity preprocessing: all intensity-dependent quantities in
Section~\ref{sec:mm-width} are evaluated on the raw 8-bit scale
$S\in[0,255]$. Instance analysis is performed on $512\times512$ crops taken on
the $128$-px tile grid used by Section~\ref{sec:mm-vector}, so that tile
boundaries are identical between a crop and its parent image.

\subsection{Input masks, problem definition and mask provenance}
\label{sec:mm-masks}

\paragraph{Problem definition.}
The input to FilaSeg is a pair: a binary centreline mask
$M\in\{0,1\}^{H\times W}$, in which the foreground marks the \emph{axis} of each
filament rather than its full silhouette, together with the paired grayscale SEM
image $S\in[0,255]^{H\times W}$ from which $M$ was derived. The mask is a thin
ribbon, nominally one to three pixels wide, and crossings are represented as
shared foreground pixels: where two filaments cross, the mask carries a single
undifferentiated foreground region and gives no indication of which pixels belong
to which filament. The required output is an instance-labelled mask: a set of
filaments $\{B_1,\dots,B_K\}$, each with a pixel support $\Omega_k$, an ordered
centreline $\mathcal{C}_k$, a scalar apparent width $w_k$, a length $\ell_k$ and
endpoints, such that each $B_k$ corresponds to one physical bundle even where
bundles cross or where the mask is locally broken. Because two crossing bundles
genuinely share pixels, output instances are permitted to overlap: the labelling
is stored as a multi-label stack rather than a single-valued label image, so that
a disputed crossing pixel can be claimed by both instances instead of being
awarded arbitrarily to one.

\paragraph{What is and is not evaluated.}
FilaSeg is evaluated primarily as a centreline-mask-to-instance method, using
synthetic masks with exact instance ground truth
(Section~\ref{sec:mm-synth}). One real SEM crop is included as a manually
annotated development case study (Section~\ref{sec:mm-real}). The upstream
method used to produce that crop's centreline mask is not evaluated in this
study. Throughout, \emph{exact ground truth} refers only to synthetic data,
where the generator defines each instance by construction, and \emph{manual
reference annotation} refers to the real crop, where the reference is one
human labelling of an ambiguous image rather than an unquestionable truth.

\paragraph{Provenance of the real masks.}
The centreline masks used in the real case study were generated by a separate
synthetic-data-driven CycleGAN/U-Net workflow~\citep{allan2026cntsem}, itself
adapted from the open particle-segmentation workflow of
\citet{ruehle2021workflow}. That upstream
workflow is not evaluated in this study and is treated only as one possible
source of FilaSeg input; any segmenter producing a thin-axis binary mask can be
substituted. Its one property that matters here is that it reconstructs the
bundle \emph{axis} rather than the full bundle silhouette, which is why the input
mask is thin and why the physical width must be recovered separately from the SEM
image (Section~\ref{sec:mm-width}).

The training-set relationship between the upstream semantic segmenter and the
real reference crop could not be reconstructed from the available records: the
segmenter was developed in a separate repository, and no training-image list,
data-split record or training log for it is present in the FilaSeg repository.
The real crop is therefore treated only as a development case study, and no
independent end-to-end SEM generalization claim is made. Because the primary
evaluation of this paper is synthetic, and its input masks are generated
procedurally rather than by any trained model
(Section~\ref{sec:mm-synth}), this gap does not affect the synthetic
instance-grouping experiments; it bounds only the interpretation of the single
real crop.

\subsection{FilaSeg overview and physical-scale adaptation}
\label{sec:mm-overview}
FilaSeg factorizes the mask-to-instances problem into four ordered stages
(Figure~\ref{fig:scope}):

\begin{enumerate}[leftmargin=1.5em,itemsep=1pt]
  \item \textbf{Hough-based vectorization} (Section~\ref{sec:mm-vector}):
  decompose $M$ into short, oriented line primitives, bridging small raster gaps
  in the process.
  \item \textbf{Orientation-aware fragment cleaning}
  (Section~\ref{sec:mm-clean}): remove specks, close along-filament gaps with
  orientation-matched morphology, and reduce each primitive to a single smooth
  two-tip curve.
  \item \textbf{Geometry-based instance reconnection}
  (Section~\ref{sec:mm-reconnect}): merge fragments into instances with a staged,
  topology-checked greedy graph merge governed by geometric gates.
  \item \textbf{SEM-gradient-based width estimation and rendering}
  (Section~\ref{sec:mm-width}): measure one apparent width per instance from the
  SEM intensity profile across the centreline, render each instance at that
  width, and resolve residual overlaps.
\end{enumerate}

The corresponding implementation modules are named \texttt{stringart},
\texttt{preprocess}, \texttt{reconnect} and \texttt{postprocess} in the released
code; the scientific names above are used throughout the manuscript.

\paragraph{Physical-scale adaptation.}
All pixel-valued defaults are tuned at the reference pixel size $u_{\text{ref}}$
of Section~\ref{sec:mm-sem} (the physical size of one pixel in the reference
acquisition). Two mechanisms let one configuration transfer to other
magnifications. First, for an image whose physical pixel size is $u$ (the
physical size of one pixel in that image), define the dimensionless
pixel-scaling factor
\begin{equation}
  s_{\text{px}} = \frac{u_{\text{ref}}}{u},
  \label{eq:spx}
\end{equation}
so that $s_{\text{px}}<1$ at a coarser pixel size. Every configured parameter is
then rescaled according to its physical dimension,
\begin{equation}
  d_{\text{px}}(u) = s_{\text{px}}\,d_{\text{px,ref}},\qquad
  A_{\text{px}}(u) = s_{\text{px}}^{2}\,A_{\text{px,ref}},\qquad
  \kappa_{\text{px}}(u) = \kappa_{\text{px,ref}}\,/\,s_{\text{px}},
  \label{eq:scaling}
\end{equation}
where $d_{\text{px,ref}}$ is any length-valued reference parameter in pixels,
$A_{\text{px,ref}}$ any area-valued reference parameter in pixels squared, and
$\kappa_{\text{px,ref}}$ the reference curvature threshold in inverse pixels;
$d_{\text{px}}(u)$, $A_{\text{px}}(u)$ and $\kappa_{\text{px}}(u)$ are their
scaled counterparts at pixel size $u$. Dimensionless parameters (intensity
thresholds, cosines, fractions, iteration counts) are left unchanged. The
physical pixel size is supplied explicitly or obtained from available SEM
acquisition metadata; the reference scale is used only as a documented
fallback. A scaled copy of the configuration is written per run so that the
source configuration is never mutated. Second, within the vectorization stage,
four parameters adapt to the image \emph{content} rather than to its nominal
scale, as described in Section~\ref{sec:mm-vector}.

Two conventions are fixed here and used throughout. Filament axes are
unoriented, so the mismatch between two axis angles $\theta_1,\theta_2$ is the
circular difference
\begin{equation}
  \Delta\theta = \min\!\big(|\theta_1-\theta_2|,\;180^\circ-|\theta_1-\theta_2|\big)
  \;\in\;[0^\circ,90^\circ].
  \label{eq:angdiff}
\end{equation}
Second, the transverse size of a bundle is reported as an \emph{apparent
projected width}: the SEM records a projected silhouette, and no assumption is
made that the bundle cross-section is circular, so the term \emph{diameter} is
avoided.

\subsection{Stage 1: tiled Hough-based residual vectorization}
\label{sec:mm-vector}
Stage 1 (implementation module \texttt{stringart}) converts the input mask into
a set of oriented line primitives. It applies a tiled, orientation-binned
residual decomposition built on the progressive probabilistic Hough transform
\citep{matas2000ppht}: within each image tile and orientation bin, it
repeatedly accepts the line segment that explains the most currently
unexplained mask pixels, which also bridges small raster gaps along the way.
Four of its parameters adapt automatically to the observed filament width
rather than to a fixed pixel count, so the same configuration transfers across
the physical scales of Section~\ref{sec:mm-overview}.

\subsection{Stage 2: orientation-aware fragment cleaning}
\label{sec:mm-clean}
Stage 2 (\texttt{preprocess}) cleans the per-orientation primitives produced by
Stage 1: it discards specks below a minimum size, closes short along-filament
gaps with orientation-matched morphology, and reduces each fragment to a
single smooth two-tip curve. This hands Stage 3 physically plausible curves
with well-defined tip geometry, rather than fragmented masks whose tip
tangents are dominated by raster noise.

\subsection{Stage 3: geometry-based instance reconnection}
\label{sec:mm-reconnect}
Stage 3 (\texttt{reconnect}) merges fragments into filament instances. It
represents the current segmentation as a set of components with skeleton tips,
and greedily joins compatible tip pairs whose local geometry, distance,
collinearity, curvature and smoothness all pass a battery of gates, including
a local-orientation crossing-prevention test that targets the characteristic
failure mode of fusing two filaments that merely cross (Figure~\ref{fig:gates}).
Thresholds are applied in three ordered passes, from safest to broadest, and a
topology-checked repair step recovers configurations that simple
endpoint-to-endpoint projection misses.

\subsection{Stage 4: SEM-gradient-based width estimation and rendering}
\label{sec:mm-width}
Stage 4 (\texttt{postprocess}) converts reconnected labels into measured,
rendered instances. For each surviving instance it measures one apparent
projected width from the paired SEM intensity profile sampled across the
centreline, using the fact that a bundle appears as a band bounded by two
opposite-polarity intensity edges; it then renders the instance at that width
and resolves residual overlaps between instances.

\subsection{Data and reference annotations}

\subsubsection{Real test crop}
\label{sec:mm-real}
One manually annotated instance ground truth is available: a $512\times512$
crop of a parent micrograph, containing 58 labelled filament instances. It
informed method development and is used only as a qualitative case study, not
a held-out population estimate (Section~\ref{sec:limitations}).

\subsubsection{Procedural synthetic benchmark}
\label{sec:mm-synth}
Manual instance annotation of a dense CNT mat is expensive, so exact ground
truth at scale comes from a procedural synthetic generator. Each filament is
rendered as a thick band with an overlap-aware instance ground truth, and the
mask FilaSeg actually consumes is a degraded thin-axis ridge of configurable
width, matching the axis reconstruction an upstream segmenter would produce.
The benchmark spans five prescribed areal coverages from $20\%$ to $60\%$.

\subsection{Evaluation metrics and statistical analysis}
\label{sec:mm-metrics}
Methods are compared on a common, method-independent partition of the input
skeleton into atomic fragments, so that FilaSeg and every baseline are scored
on one fixed partitioning problem regardless of instance numbering.

\reviewnote{Detailed methods text intentionally omitted from this simplified
review draft.}

\subsubsection[Primary metric: common-fragment pairwise F1]
{Primary metric: common-fragment pairwise \Fone{}}
\label{sec:mm-f1}
The primary endpoint is pairwise grouping \Fone{} over pairs of common
fragments: precision penalizes fragment pairs from different filaments that
were merged (over-merging), and recall penalizes fragment pairs from the same
filament that were left separate (under-merging). The locked primary
comparison reduces every method's output to an equivalent one-pixel
centreline before scoring, so that grouping accuracy is assessed separately
from Stage-4 width rendering.

\subsubsection{Object-level instance recovery}
\label{sec:mm-instance}
A count-based companion to the pairwise \Fone{} classifies each ground-truth
filament as well recovered, deleted (absorbed into another instance), or
fragmented (split across several predicted instances), and each predicted
instance with no dominant ground-truth match as false.

\subsection{Configuration locking, baselines and ablation protocol}
\label{sec:mm-protocol}
All synthetic and real development data were used to tune the method and
select baseline operating points before the FilaSeg configuration and baseline
parameters were frozen; a disjoint set of previously unevaluated geometries
was then scored once, with no further tuning. The connected-component sanity
check labels every connected component of the mask with no gap reconnection
or junction resolution; the main comparator skeletonizes the mask and greedily
continues branches through junctions or gaps by minimum turning angle, with
only its maximum gap and maximum turn selected from development data.

\subsection{Implementation}
\label{sec:mm-impl}
FilaSeg is implemented in Python on the standard scientific stack (NumPy,
SciPy, scikit-image, OpenCV, Matplotlib, tifffile, PyYAML), as four separate
stage modules orchestrated by a single end-to-end runner. The commands that
reproduce every number in this paper are listed in Appendix~\ref{app:repro}.
