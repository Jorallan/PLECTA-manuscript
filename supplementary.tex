%  No stray one-line fragments. A float can push the tail of a paragraph onto
%  the next page, where one line under a table reads as a typo rather than as
%  the end of a sentence from the page before -- the "Section 3.5." case. These
%  penalties refuse to break a paragraph so that a single line is left behind
%  (club) or carried over (widow). 10000 is a prohibition rather than a cost,
%  so TeX moves the whole paragraph instead; \raggedbottom lets the resulting
%  slack fall at the foot of the page rather than stretching the text.

\clubpenalty=10000
\displaywidowpenalty=10000
