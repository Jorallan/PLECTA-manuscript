\section*{Data and code availability}
The PLECTA source, complete fixed configuration, compact seed manifest,
and aggregate machine-readable evidence are available at
\url{https://github.com/Jorallan/PLECTA}; the version used in this paper is
archived at Zenodo \citep{allan2026plectazenodo}. A graphical application that
performs the same segmentation on a supplied mask is available at
\url{https://github.com/Jorallan/PLECTA_APP}. The
annotation tool of Section~\ref{sec:mm-real} is at
\url{https://github.com/Jorallan/ImageAnnotator}; it is listed because the
machine-assisted annotation protocol described there is implemented in it.
The manual annotations of the three SEM fields will be deposited in
4TU.ResearchData upon acceptance.
