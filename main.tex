\reviewnote{A broader upstream pipeline also exists around the method
described in this manuscript: real SEM images and procedurally generated
masks $\to$ CycleGAN image translation $\to$ U-Net semantic segmentation
$\to$ binary CNT bundle-axis mask $\to$ FilaSeg instance extraction $\to$
SEM-assisted Stage-4 width estimation, overlap handling, and rendering.
This manuscript currently treats the binary axis mask as the formal input
and evaluates only the instance-extraction stages. Open questions for
supervisor feedback:
\begin{itemize}[leftmargin=1.4em,itemsep=1pt]
  \item Should the complete upstream CycleGAN/U-Net pipeline be integrated
  into this paper?
  \item Should it instead remain a separate paper or companion workflow?
  \item Should the current manuscript continue to treat the binary axis mask
  as the formal input?
  \item How much of Stage 4 should be presented as part of instance
  extraction versus a separate SEM-assisted measurement/postprocessing stage?
\end{itemize}
}

\section*{Data and code availability}
The FilaSeg source code, the procedural synthetic benchmark generator, the
evaluation subsystem, and the manually annotated real test crop are contained in
the accompanying repository. Every numerical result reported here is reproducible
from that repository using Appendix~\ref{app:repro} together with the full
reproducibility record distributed with the manuscript.
\aq{a journal will require a citable archived release (for example a Zenodo DOI
or a tagged GitHub release) rather than a bare repository URL; and
Section~\ref{sec:limitations} notes that the evaluation subsystem must be
committed and a clean checkout confirmed to reproduce the reported numbers before
submission}

\section*{Acknowledgements}
The authors thank the maintainers of the open-source scientific-Python stack
(NumPy, SciPy, scikit-image, OpenCV, Matplotlib) on which this work is built.
The binary centreline masks used in the real case study were produced by a
separate synthetic-data-driven segmentation workflow (Section~\ref{sec:mm-masks})
that adapts the open CycleGAN/U-Net particle-segmentation workflow of Rühle and
colleagues at BAM (Bundesanstalt für Materialforschung und
-prüfung)~\citep{ruehle2021workflow}; that workflow is not evaluated here and we
gratefully acknowledge its authors.
