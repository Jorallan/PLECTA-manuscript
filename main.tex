\section*{Data and code availability}
The PLECTA source, complete fixed configuration, compact seed manifest,
and aggregate machine-readable evidence are available at
\url{https://github.com/Jorallan/PLECTA}. A graphical application that runs the
same reconstruction on a supplied mask, for readers who would rather not call
the library directly, is at \url{https://github.com/Jorallan/PLECTA_APP}. The
annotation tool of Section~\ref{sec:mm-real} is at
\url{https://github.com/Jorallan/ImageAnnotator}; it is listed because the
reference is machine-assisted rather than freehand, so the ridge snapping,
spline re-rendering and full-width-at-half-maximum widths it applies are part
of how the reference every real-field score is taken against was made.
The manual annotations of the
\PlectaRealFieldCountLower{} SEM fields, from both annotators and in the form
the scorer reads, will be deposited in 4TU.ResearchData. Generated scenes,
detailed per-scene
records, and development diagnostics are retained locally.
